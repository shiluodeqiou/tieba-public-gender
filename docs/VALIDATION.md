# 验证记录

日期：2026-10-12（Asia/Shanghai）。版本：1.0.1。

## 已实际检查

- 在内置浏览器打开用户反馈的真实电脑帖子，确认它使用新版 Vue 页面；旧选择器匹配 0 个作者，新选择器 `.user-info .name-info > a.head-name` 匹配 11 个作者位置，包含主楼、回复和楼中楼。
- 新版作者主页链接提供 `id=tb.*` 公开账号标识；头像、外围链接和正文中的提及不作为作者位置。
- 不携带登录 Cookie 请求 `/home/get/panel?ie=utf-8&id=...`，得到 HTTP 200、`no: 0`、`data.sex: "male"`。返回的 `data.portrait` 与请求标识一致，但附带 `?t=数字时间戳`，已据此增加规范化和严格核对。
- 1.0.0 发布前曾匿名请求 `un=...`：两个样本均为 HTTP 200、`no: 0`，分别返回 `female` 和 `male`；`data.name` 与请求账号匹配。
- 未将完整资料响应、真实账号样本或帖子正文纳入项目测试及交付文件。
- 阅读 Tampermonkey 官方请求文档，确认 `anonymous` 和 `@connect` 的用途。由于匿名请求会进入 fetch 模式，脚本另设取消计时器，不只依赖扩展的 `timeout`。
- 在内置浏览器的本地合成新版页面载入同一份交付脚本，实际点击关闭/开启、隐藏/显示未知及重新查询按钮；可见标记和面板状态均同步变化。页面不联系真实资料接口，此项不代表用户 Edge 中的油猴安装验收。

## 安装后快速验收

1. 点击项目安装链接更新至 1.0.1，刷新电脑网页版帖子；右下角应显示版本及“已开启”。
2. 等待查询，确认作者数量大于 0，昵称旁出现男、女或未知标记；未知原因会显示在面板或标记提示中。
3. 点击“关闭标记”，确认状态变为“已关闭”、标记移除；再点击“开启标记”恢复。刷新后开关设置应保持。
4. 展开楼中楼，确认新作者也能显示标记；正文中的被回复者和 @ 提及不会被误当作作者。
5. 点击“隐藏未知/显示未知”和“重新查询”，确认面板数量与标记同步，无需重新加载整页。
6. 可选：从列表通过站内跳转进入帖子检查面板出现，再返回列表检查面板消失。
